Problem Statement

Railway Safety Requires Real-Time Monitoring

🔩

Fastener Defects

Missing or loose rail fasteners cause track misalignment and derailment risk.

⚡

Rail Cracks

Micro-cracks propagate under load — early detection prevents catastrophic failure.

🚧

Track Obstacles

Debris, animals, and objects on the track require immediate automated alerts.

Challenge: Traditional inspection is manual, infrequent, and expensive. We need an always-on, edge-AI system that runs on embedded hardware — no cloud, no PC, real-time detection at trackside.

CameraTask priority 4

Captures RGB frame from DCMIPP PSRAM buffer. Signals InferenceTask via semaphore.

InferenceTask priority 5

Runs stai_network_run() on NPU. Decodes detections and dispatches real-time telemetry packets.

AlertTask priority 6

Receives mailbox from InferenceTask. Sends JSON over UART. Controls LEDs.

ST Edge AI Core → INT8

Flash to STM32N6
